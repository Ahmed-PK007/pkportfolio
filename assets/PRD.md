\# Personal Portfolio Website



\## Overview



Build a premium, modern, high-performance personal portfolio website using the provided Notion export as the primary content source.



This is NOT a Notion clone.



The final website should feel like a premium SaaS product website inspired by Apple, Stripe, Linear and Vercel while maintaining excellent readability and usability.



The website should represent a senior Performance Marketing Strategist.



\---



\# Objectives



The website should:



\- Build trust immediately.

\- Showcase expertise.

\- Present case studies beautifully.

\- Generate client inquiries.

\- Feel premium without unnecessary visual effects.



Every design decision should prioritize:



\- Trust

\- Clarity

\- Simplicity

\- Performance

\- Accessibility



Avoid flashy animations or experimental UI.
